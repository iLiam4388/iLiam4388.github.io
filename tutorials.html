Start here

Open Home →
Navigate iLiam
  1. Open Home and choose Videos, Photos, Downloads, Community, Liam Store, Games or Other. Other contains Whiteboard, 3D Rider, 2D Rider and Tutorials.
  2. Use Back Home to return to the main menu. A New Stuff tag identifies a page with updates.
  3. Read Latest Stuff on Home to see recent changes.
Try it on iLiam →
Create an account
  1. Open Community and choose Sign Up in the sign-in window.
  2. Enter a unique username (at least 3 characters), a public nickname and a password (at least 6 characters). Confirm the password and select Sign Up.
  3. Keep your password private. Your username is permanent, but your nickname can change.
Try it on iLiam →
Log in and manage your profile
  1. Choose Log In and enter your existing username and password. Use the same account across iLiam.
  2. In Community, select Profile. Change your public nickname and select Save Profile. The profile picture field is currently hidden; an automatic avatar is used when no picture is stored.
  3. Use Sign Out on a shared device. Delete Account is destructive; do not use it merely to log out.
Try it on iLiam →
Notifications and announcements
  1. If iLiam asks to enable browser notifications, choose Enable notifications and approve the browser prompt if you want alerts.
  2. Use the Notifications button to manage announcements and upvote/featured-post alerts. Browser notifications require permission and generally work while an iLiam page is open.
  3. If permission is blocked, check browser site permissions. Respect device and network policies; in-page notices may still work.
Try it on iLiam →

Community and posts

Open Community →
Explore the Community feed
  1. Open Community and sign in if asked. Scroll through the posts. Featured posts have a special label.
  2. Use the top buttons to reach Saved Posts, Call Someone, Messages, Public Chat and Profile.
  3. Use posts for things worth sharing with everyone; use Messages or Public Chat for everyday conversations.
Try it on iLiam →
Write a post
  1. Under Post Something, enter your text. Use B, I or U to format selected text, or use the formatting markers shown in the composer.
  2. Select Post when ready. Posts are public to the Community, so do not include private information.
  3. Use Show posting guidelines to restore the guidance if you previously dismissed it.
Try it on iLiam →
Add a clickable link
  1. In the composer, select Link. Enter the link text and a valid HTTP or HTTPS address, then insert it using the link dialog.
  2. Review the text before posting. Readers can click the link to open the destination.
  3. Only share links you trust.
Try it on iLiam →
Share images and galleries
  1. Copy a direct, publicly accessible image URL beginning with https://. In Post Something, select Image, paste the address and select Add.
  2. Check the attachment chip; remove it with its × if you chose the wrong image. Repeat to attach more images, then select Post.
  3. When several images form a gallery, scroll horizontally to see them. This is URL-based sharing, not uploading a local file to iLiam; an image that requires a login or blocks embedding may not appear.
Try it on iLiam →
Share a video
  1. Select Video in the post composer. Paste a supported YouTube or direct video address and select Add.
  2. Check the attachment, add any accompanying text and select Post. Supported videos can be played in the post; others may appear as links.
  3. Do not paste a video address into the Image field.
Try it on iLiam →
Upvote, comment and reply
  1. Find a post and select Upvote to support it. You can upvote a post once.
  2. Open the comments, type a comment and submit it. Use Reply on a comment to continue that thread, and the like button to support a comment.
  3. Expand or collapse comments and replies using their controls. Use replies instead of making a separate post about the same conversation.
Try it on iLiam →
Save posts and find profiles
  1. Select Save on a post. Open Saved Posts at the top to see your saved items; select Saved again on a post to remove it from your list.
  2. Select a person's name or avatar to open their public profile, view posts and follow or unfollow them.
  3. A legacy post is an archived text-only post; some interactions and media are no longer available.
Try it on iLiam →
Delete your content
  1. Use Delete Post on your own post if you want to remove it. Use the available delete control on your own comment or reply.
  2. Read any confirmation carefully. Deletion is not the same as hiding or unsaving a post.
  3. Moderation controls are available only to authorized administrators.

Private and group messages

Open Community →
Start a private conversation
  1. Open Community, select Messages and then Add user.
  2. Search for a username or display name. Select one person and choose Create chat.
  3. Choose the conversation, type a message and select Send.
Try it on iLiam →
Create and edit a group chat
  1. In Messages, select Add user and choose multiple people. Enter a group name, then choose Create chat. Groups support up to four people total.
  2. Open the group and use Edit group if available. Authorized members can manage the group name, picture and membership.
  3. Select Save changes. Check the member list before sharing anything private.
Try it on iLiam →
Reply to a specific message
  1. Choose Reply on the message you want to answer. A reply preview appears above the composer.
  2. Write and send your answer. Select × on the reply preview if you want to cancel it.
  3. If the original message is removed or no longer retained, the quoted message may be unavailable.
Try it on iLiam →
Send images, videos and links in Messages
  1. Open a conversation. Use Image or Video to add a supported media URL, or Link to enter link text and a website address.
  2. Confirm the attachment in the media dialog, check the composer and select Send. Remove unwanted attachments before sending.
  3. Regular media attachments use URLs; the group-picture control is a separate local file chooser.
Try it on iLiam →
Message privacy and cleanup
  1. In Messages, open Settings. Enable Do Not Disturb for messages if you want to mute message notifications, or search for a user and choose Block or Unblock.
  2. Use the available Delete control to remove your own message. Read the confirmation before deleting a conversation; changes can affect other participants.
  3. Messages have retention limits, so do not treat iLiam as permanent archival storage.
Try it on iLiam →

Public Chat

Open Community →
Join the public conversation
  1. Open Community and choose Public Chat. Read the existing conversation, type a message and select Send.
  2. Use Reply on an existing message to keep the conversation clear. Use × to cancel a reply before sending.
  3. Public Chat is visible to other users; keep passwords, addresses and private information out of it.
Try it on iLiam →
Share media and links in Public Chat
  1. Choose Image or Video, paste the appropriate media URL and select Add. Use Link for clickable link text and an HTTP(S) website address.
  2. Check the attachment and send the message. Remove incorrect attachments using ×.
  3. Use Delete on your own messages when available. Older chat messages may be removed under retention limits.
Try it on iLiam →

Audio, video and screen sharing

Open Community →
Start a private or group call
  1. Open Community and select Call Someone. Search for users and select one person for a private call or up to three others for a group call.
  2. Choose Audio call or Video call. Allow microphone and camera access when needed, and wait for the other people to accept.
  3. You can also open a Messages conversation and use its call menu. Only call people who agree to participate.
Try it on iLiam →
Answer or decline a call
  1. When an incoming call appears, check who is calling. Select Accept to join or Decline to dismiss it.
  2. Grant the requested browser permissions if you choose to join. Call alerts may also appear on other iLiam pages.
  3. Use Leave call or End call to disconnect when finished.
Try it on iLiam →
Control your microphone and camera
  1. During a call, use Mute to stop transmitting your microphone and Unmute to turn it back on.
  2. Use Camera off or Camera on to control your camera when available.
  3. If incoming sound does not play, select Play audio or Play sound. Check device volume and browser permissions.
Try it on iLiam →
Share your screen safely
  1. During an active call, select Share screen. In the browser's chooser, select the tab, window or screen you intend to share and confirm.
  2. Prefer a single tab or window. Close sensitive content first, and share only with people you trust. Screen sharing does not give the viewer control of your computer.
  3. Select Stop sharing or the browser's stop control when finished. Device policy and browser support may limit this feature.
Try it on iLiam →
Use Picture in Picture
  1. Wait until another participant's video appears. Select Picture in Picture to open a floating video window when supported.
  2. Switch to another tab if needed, while keeping the call page open. Close the floating player or use its browser controls to return.
  3. If the browser does not support Picture in Picture, continue using the regular call window.
Try it on iLiam →
Call privacy and troubleshooting
  1. Open Call Someone. Use Edit to manage blocked people and Done to return. Use Do Not Disturb to avoid unwanted incoming calls.
  2. Enable call notifications if desired and the browser allows them.
  3. If a call does not connect, verify both users are online, check microphone/camera permissions, and try again on an allowed connection. Some networks restrict real-time calls.
Try it on iLiam →

Photos, videos, downloads, games and store

Open Home →
Browse and download photos
  1. From Home, open Photos. Browse the gallery and choose Download under an image to save it.
  2. Your browser handles the file download. Check its downloads list if you cannot find it.
  3. The gallery is a site catalog, not the Community image-posting form.
Try it on iLiam →
Watch and download videos
  1. Open Videos from Home and use the media player controls to watch a video.
  2. Choose Download beneath a video when you want a local copy. Some browsers may open media directly instead.
  3. Use only files and content you have permission to access.
Try it on iLiam →
Download files
  1. Open Downloads and browse the file cards. Choose the download action for the desired item.
  2. Find the file in your browser's downloads list. If the file is unavailable, report it rather than repeatedly retrying.
  3. Follow your device's rules for opening downloaded files.
Try it on iLiam →
Play a game
  1. Open Games. Browse or search the available games, and select one to open the player.
  2. Use Reload to restart the embedded page, Full Screen to expand it, or Close to return to the list.
  3. Some games require keyboard controls, internet access or browser capabilities that may be unavailable on your device.
Try it on iLiam →
Browse Liam Store
  1. Open Liam Store from Home. Read the product card and choose its action to visit the linked storefront when available.
  2. Review the external seller's price, terms and checkout information before purchasing.
  3. Do not enter payment information into Community posts or messages.
Try it on iLiam →
Write a review
  1. Scroll to Reviews on Home and sign in with your iLiam account if needed.
  2. Choose a rating from one to five stars, enter your feedback and select Post review.
  3. Use Like or Show replies to interact with reviews. Keep feedback useful and respectful.

iLiam Whiteboard

Open iLiam Whiteboard →
Draw your first whiteboard
  1. Open Other, then Open Whiteboard. Select New if you want a blank board. Name your board in the title field.
  2. Select Pen or Marker, choose a color and size, then drag across the canvas. Use Eraser to remove marks.
  3. Use Undo and Redo for recent changes. Use Move to pan and the zoom controls or Fit to adjust the view.
Try it on iLiam →
Add shapes, text and notes
  1. Choose Line, Arrow, Box or Circle and drag to create a shape.
  2. Choose Text or Note to add labels or sticky notes. Set color and size using the tool options.
  3. Use Grid and Paper to change the canvas appearance.
Try it on iLiam →
Create a shared board
  1. Sign in to iLiam and select Collaborate, then Create shared board.
  2. Use General access and Invite an iLiam account to control who can view and edit. Restricted access allows only invited accounts; the interface supports up to 20 invitees.
  3. Share the room link or code only with intended collaborators. Use Leave shared room when finished.
Try it on iLiam →
Join someone else's whiteboard
  1. Open Whiteboard and select Collaborate. Find an invited board, or paste a room code or shared link and select Join.
  2. Make sure you are using the correct iLiam account if access is restricted.
  3. Work together on the canvas. Ask before clearing or making major changes to a shared board.
Try it on iLiam →
Save, reopen and export a board
  1. Select PNG for an image export. Under the more-actions menu, use Export SVG for a vector file or Save .iliamboard file to keep an editable project.
  2. Use Open .iliamboard file to load an existing project. Keep a backup before clearing or creating a new board.
  3. Do not rely on unsaved local drafts being retained.
Try it on iLiam →

2D Rider

Open 2D Rider →
Build a 2D scene
  1. Open Other, then 2D Rider. Choose Build and add a Rectangle, Circle, Triangle, Star, Hexagon or Text.
  2. Tap or click an object to select it, drag it to move, or select it from Scene.
  3. Use the Edit panel to duplicate, delete, name, rotate, scale or position the selected object precisely.
Try it on iLiam →
Change colors, shaders and text
  1. Select an object and open Edit. In Surface, choose a Color and Shader such as Flat, Gloss, Metal or Neon.
  2. For text objects, use the Text controls to change the words and font. Use the available font import control if desired.
  3. Adjust transforms and preview the result on the canvas.
Try it on iLiam →
Animate a 2D object
  1. Select an object, open Edit and add a keyframe at the current time in Animation.
  2. Open Animate, move the time slider to a later point, change the object's transform, and add another keyframe.
  3. Use Play to preview the animation and Reset to return to the beginning.
Try it on iLiam →
Try physics, metaballs and liquid
  1. In Build, add a metaball shape or choose Add liquid. Nearby metaballs merge; liquid uses particle simulation.
  2. Select an object, open Edit and choose a Physics body type: rigid, soft or static collider. Adjust available body settings.
  3. In Animate, adjust world gravity and floor collision, then Play. Start with a small scene for better performance.
Try it on iLiam →
Save and export 2D projects
  1. Open Project and select Save project for an editable .2drider file or Export PNG for an image.
  2. Use Open project to load a saved file, and New scene to start over. Use Undo and Redo when needed.
  3. On touchscreens, drag empty space to pan, pinch to zoom, and use Fit to reset the view. Save a copy before leaving.
Try it on iLiam →

3D Rider

Open 3D Rider →
Create your first 3D model
  1. Open Other, then 3D Rider. Start with a Box, Sphere, Cylinder, Cone, Torus, Plane or another available shape.
  2. Select the object in the viewport or Scene collection. Use the Inspector to change its Transform and Shape.
  3. Drag empty space to orbit, right-drag or use a two-finger drag to pan, and use zoom controls. Open Controls & shortcuts for device-specific controls.
Try it on iLiam →
Edit meshes, text and materials
  1. Choose an object and inspect the Mesh modeling tools when supported. Use the available modeling controls to modify geometry.
  2. Use Transform for placement, rotation and scale; Text for editable lettering; Material for color, shader and presets.
  3. Switch between Material, Wireframe and Rendered views to inspect the result. Frame selection to focus on an object.
Try it on iLiam →
Create organic shapes and lighting
  1. Add a Metaball and choose a variant such as Sphere, Capsule, Chain, Ring, Cluster or Sheet. Adjust its shape in the Inspector.
  2. Add a Point light to illuminate the scene. Use its Inspector options and Studio settings to change the look.
  3. Experiment with materials and rendered view to see the effect of lighting.
Try it on iLiam →
Animate and simulate 3D objects
  1. Open Animation, choose an object and set a keyframe using the available timeline controls.
  2. Move to a later time and change the object's transform, then add another keyframe. Preview playback and remove unwanted keyframes.
  3. In Physics, choose Static collider, Rigid body or Soft body when applicable, adjust settings, and run the simulation using the available controls.
Try it on iLiam →
Save, render and export 3D projects
  1. Use Save project to keep an editable scene and Open project to return to it later. Use New project to start fresh.
  2. Select Render PNG for an image; Export GIF or Export MP4 for animation. Choose an available resolution and frame rate in the export dialog.
  3. Use Export STL or Export OBJ for compatible 3D tools. Supported export options may vary by browser and scene. Save a backup before closing.
Try it on iLiam →

Troubleshooting and good habits

Open Other →
Something is not working
  1. Refresh the page if a control is stuck, but save unfinished creative work first. Check whether you are signed in and the service is connected.
  2. Verify browser permissions for calls, notifications and screen sharing. Follow the device owner's policies if an option is disabled.
  3. Try another supported browser on a device you are allowed to use, or report the issue with the page name, error message and steps to reproduce.
Try it on iLiam →
Keep your account and work safe
  1. Use a unique password and sign out on shared devices. Do not post sensitive information or share your login.
  2. Block unwanted contact, use Do Not Disturb, and decline unfamiliar calls. Ask permission before sharing someone else's content.
  3. Save creative project files locally when needed. Posts and conversations may have retention limits, so keep your own copies of important work.
